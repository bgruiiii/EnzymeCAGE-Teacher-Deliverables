# 六模型降解路径与酶预测 Hit@1

本页汇总121题×6模型的现成原答，给出整链、单步反应和Gold目标酶的参考命中率。新增API调用0。

| 模型 | 整条认可主链 Hit@1 | 单步反应 Hit@1 | 目标完整EC Hit@1 |
|---|---:|---:|---:|
| Grok | 6/120（5.00%） | 90/515（17.48%） | 62/374（16.58%） |
| Kimi | 5/120（4.17%） | 85/515（16.50%） | 61/374（16.31%） |
| GLM | 3/120（2.50%） | 64/515（12.43%） | 39/374（10.43%） |
| DeepSeek | 6/120（5.00%） | 63/515（12.23%） | 37/374（9.89%） |
| Qwen | 5/120（4.17%） | 54/515（10.49%） | 28/374（7.49%） |
| GPT5.6 | 1/120（0.83%） | 45/515（8.74%） | 24/374（6.42%） |

整链主表分母120题：071主链范围未定，仍保留在121题清单。单步分母515个Gold目标，完整EC分母374；未能对齐的目标计未命中而非已证伪。酶对照Gold目标反应，反应未命中不自动使酶失分。精确口径、对应覆盖和敏感性请看完整报告。

**为什么只测Hit@1？** 模型每题提交一份首选完整方案，包含路径、反应、酶、微生物及性状；未输出按相关性排序的3或5份备选。链内多个步骤、旁支和第二次重试均不能冒充Top-3/5。因此Hit@3/5不适用，不填0、不事后拼候选。
