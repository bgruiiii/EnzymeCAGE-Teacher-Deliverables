Route A

A：外部专业反应预测工具

本轮正式结论：NOT SCOREABLE

本轮测试对象与实测

BioTransformer 3.0，Environmental Microbial backend EnvMicroBTransformer / ENVMICRO， 固定源码 commit 7149f7ec6b2f32f9f789bab53aa4a71db49e59e2。

26 raw product rows
25/26 RDKit 可解析
4/6 可解析子集 case 诊断命中，非正式分数
1.09–1.27 s 每 case wall time
RP-P06 有 1 条原始产物碳显式价态超限。没有人工修复或静默删除后再补算正式成绩。

优点

  • 规则、源码、命令和运行资产较容易冻结。
  • 6/6 有效 case 均完成执行，单 case 速度较快。
  • ENVMICRO 的领域描述与环境微生物转化相关。
  • 如果更换为原生输出完整反应的工具，工程可复现性可能较好。

缺点 / 风险

  • 当前只给产物集合，没有完整反应。
  • 没有合法 native rank 和可用 confidence。
  • 1/26 产物不可解析，必须 fail-closed。
  • 不能从当前输出直接恢复 Rhea、EC 或 D4 候选池。
  • Maven SNAPSHOT 依赖使完整重建证明仍不充分。
如果选择 A： 不直接接入当前 BioTransformer v0.5。应先筛选新的专业工具，冻结版本、依赖、 完整反应、rank/confidence 和 provenance 语义，再用新的 blind set 重测。

优点

  • 本轮唯一直接展示“从底物生成新候选产物”的路线。
  • 三个独立模型均在 4–5/6 case 上找回主要产物。

  • 平台模型版本可复现性弱。
  • 模型生成时间和外部成本没有统一可靠记录。
如果选择 B： 当前 product-only 不进生产。下一步用新的 blind set 直接验证完整生化反应生成， 加上 RDKit、元素守恒、形式电荷、方向、底物保留、模型版本与 provenance 硬门。

身份边界： R1/R2 是学生侧/Codex 后续建议，不是黄老师原始 A/B/C 选项；两项均未执行、 未评分、没有命中率/Rhea/EC/酶池成绩，也不构成实施授权。
附加工程兼容性实验

R1：product-only → Rhea 有方向桥接

底物 S→ LLM 产物 P→ S >> P→ 正向两侧相似→ 冻结完整 Rhea

只比较 S 对 reference reactants、P 对 reference products；不使用反向最大值 将逆反应误作降解。只有桥接出的冻结完整 Rhea 反应可进入下游。

能力上限： 可测试产物侧信息是否改善已知 Rhea 找回；无法解决真正库外完整反应预测。

学生侧建议优先

R2：直接生成完整生化反应 blind pilot

底物→ 完整 reactants >> products→ RDKit→ 守恒/电荷/方向→ 下游衔接

直接检验黄老师的完整 reaction contract，并理论上保留真正库外反应能力； 但生成难度和失败风险高于 product-only。

建议顺序： 若正式选择 B，优先做 R2；R1 只作为附加工程实验。
