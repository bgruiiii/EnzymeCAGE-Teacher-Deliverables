整理日期：2026-08-26  
用途：线下给师姐/老师解释这次“从一步产物预测扩展到多步降解路线预测”的来龙去脉。

## 1. 一句话先讲明白

这次我们做的事情是：

```text
把原来只看“污染物第一步会变成什么”的测试，
扩展成“污染物往下走几步之后，工具能不能恢复出 BBD 已知降解路线”的测试。
```

最后比较了 3 类工具路线：

```text
1. BioTransformer：规则/经验型工具，预测比较保守。
2. enviPath BBD Rules：基于 BBD 规则，结果可解释，但覆盖偏弱。
3. ECLIPSE：深度学习产物预测模型；分为带 EC 条件的 PREDEC 版本和不带 EC 的 NoEC 版本。
```

最重要的结论是：

```text
如果只看“有没有摸到真实下游产物”，ECLIPSE PREDEC 最强。
如果用更严格的路线结构相似度评分，BioTransformer 的整体结构分最高。

原因是：ECLIPSE PREDEC 很会撒网，能覆盖到很多真实节点；
但它也会生成很多错误分支，所以一旦惩罚错误分支，综合结构分会下降。
BioTransformer 覆盖没那么猛，但乱分支少，所以结构更干净。
```

这不是矛盾，而是两个问题：

```text
ECLIPSE PREDEC：更会“找得到”。
BioTransformer：更会“少乱猜”。
```

## 2. 为什么要做这个测试

我们之前做过 BBD83，一开始主要是测试：

```text
给一个污染物底物，看工具能不能预测第一步产物。
```

但是师姐现在提出的是更接近真实应用的问题：

```text
污染物不是只反应一步就结束；
我们更想知道它能不能一路往下被降解，形成一条或多条降解路线。
```

所以这次我们把任务从“一步产物”扩展成了“多步路线”。


## 4. 怎么保证测试没有泄露答案

我们把数据分成两部分：

```text
盲测输入：只给工具看污染物本身，不给下游产物答案。
本地答案：真实 BBD 路线只保留在本地，用来最后评分。
```

也就是说：

```text
chenyu/HPC 那边只负责跑工具预测；
它不读答案、不评分。
```

工具跑完以后，把预测结果打包回来，我们再在本地用 restricted answer 做审计和评分。

这样做的目的很简单：

```text
避免工具或执行过程提前看到答案。
```

## 5. 工具具体是怎么跑的

这次主要有四条结果：

```text
1. BioTransformer ENVMICRO
2. enviPath BBD Rules
3. ECLIPSE PREDEC
4. ECLIPSE NoEC
```

其中：

```text
ECLIPSE PREDEC = ECLIPSE + EC 条件
ECLIPSE NoEC = ECLIPSE 不给 EC 条件
```

EC 可以粗略理解成“酶反应类型提示”。

所以 PREDEC 和 NoEC 的比较可以回答一个问题：

```text
给模型一个酶反应类型提示，会不会让预测更好？
```

结果显示：

```text
有帮助。
```

## 6. 第一步产物预测结果

第一步产物预测，就是只看：

```text
污染物 A → 第一代产物 B
```

不继续往下走。

这里用 Hit@1 / Hit@3 / Hit@5 / Hit@10。

最直白地说：

```text
Hit@1：工具排第一的答案有没有命中真实第一步产物。
Hit@3：工具前 3 个候选里有没有真实第一步产物。
Hit@5：工具前 5 个候选里有没有。
Hit@10：工具前 10 个候选里有没有。
```

一步预测结果如下：

| 工具 | Hit@1 | Hit@3 | Hit@5 | Hit@10 | 直白解释 |
|---|---:|---:|---:|---:|---|
| ECLIPSE PREDEC | 33/92 = 35.9% | 62/92 = 67.4% | 70/92 = 76.1% | 74/92 = 80.4% | 第一步预测最强 |
| BioTransformer | 31/92 = 33.7% | 43/92 = 46.7% | 52/92 = 56.5% | 52/92 = 56.5% | 中等 |
| ECLIPSE NoEC | 29/92 = 31.5% | 47/92 = 51.1% | 50/92 = 54.3% | 52/92 = 56.5% | 去掉 EC 后下降 |
| enviPath BBD Rules | 24/92 = 26.1% | 42/92 = 45.7% | 45/92 = 48.9% | 45/92 = 48.9% | 可解释但偏弱 |

这一部分的结论：

```text
只看第一步，ECLIPSE PREDEC 最好。
尤其 Top10 能覆盖 74/92，也就是 80.4% 的 case。
```

## 7. 多步预测第一版：大图覆盖率

然后我们让工具继续往下预测：

```text
污染物 A
→ 预测第一步产物
→ 再拿第一步产物继续预测第二步
→ 再继续预测第三步、第四步……
```

这次最多往下走：

```text
6 步
```

第一版多步评分比较像是在问：

```text
工具生成的大路线图里面，有没有碰到 BBD 真实路线里的节点？
```

结果：

| 工具 | 第一步 case 命中 | 任意下游节点命中 | BBD-local 终点节点命中 | 精确反应边命中 | 直白解释 |
|---|---:|---:|---:|---:|---|
| ECLIPSE PREDEC | 81/92 = 88.0% | 89/92 = 96.7% | 67/92 = 72.8% | 80/92 = 87.0% | 覆盖能力最强 |
| ECLIPSE NoEC | 70/92 = 76.1% | 80/92 = 87.0% | 52/92 = 56.5% | 62/92 = 67.4% | 无 EC 也有能力，但弱于 PREDEC |
| BioTransformer | 59/92 = 64.1% | 71/92 = 77.2% | 44/92 = 47.8% | 60/92 = 65.2% | 可以作为 baseline |
| enviPath BBD Rules | 53/92 = 57.6% | 62/92 = 67.4% | 30/92 = 32.6% | 52/92 = 56.5% | 规则法覆盖偏弱 |

这版结果说明：

```text
ECLIPSE PREDEC 很容易在多步扩展中摸到真实路线里的下游产物。
```

但是这里有一个问题：

```text
如果一个工具每一步都生成很多候选，路线图会变得很大。
图越大，越容易“碰巧包含答案”。
```

所以单纯看“有没有碰到”会偏宽松。

---

## 8. 为什么后来又加了更严格的评分

我们意识到：

```text
大图覆盖率好看，不等于路线预测真的科学。
```

举个简单例子。

真实路线是：

```text
A → B → C
```

工具预测：

```text
A → B → C
A → X
A → Y
A → Z
```

它确实碰到了 B 和 C，但它也多预测了 X、Y、Z。

如果只看“有没有碰到 B/C”，它看起来很好。

但真正评价路线质量时，应该惩罚这些错误分支。

所以我们又做了一个更严格的结构评分。

---

## 9. 更严格的评分标准是什么

我们参考了 enviFormer 的多步评价思想。

但是不能完全照搬它的原版评分，因为原版需要“每一步预测概率”。

这几个工具的情况不一样：

```text
ECLIPSE 有模型分数；
BioTransformer 没有可比较的概率；
enviPath BBD Rules 是规则命中，也不是可比较的概率。
```

所以我们不能拿它们的分数直接相乘，也不能说这是原版 enviFormer 概率评分。

我们采用了一个更公平的折中办法：

```text
每个工具每一步都只允许保留固定数量的候选。
然后比较它生成的路线图和真实路线图有多像。
```

这个评分在文件里叫：

```text
MG-Structural@K
```

给师姐解释时可以不用记英文名，直接理解成：

```text
固定分支数量的多步路线结构相似度评分。
```

---

## 10. K=1、K=3、K=5 分别是什么意思

K 表示：

```text
每一步最多允许工具保留几个候选产物继续往下走。
```

所以：

```text
K=1：每一步只让工具选第 1 个候选继续走，最严格。
K=3：每一步允许前 3 个候选继续走，给一点容错。
K=5：每一步允许前 5 个候选继续走，覆盖更高，但更容易乱分支。
```

K 越大，一般会出现：

```text
真实路线更容易被碰到；
错误分支也会更多。
```

所以我们主看 K=1、K=3、K=5。

K=10 也算了，但只作为宽松补充，不作为主结论。

## 11. 路线结构相似度是怎么算的

我们对每个污染物单独算一个相似度。

公式可以直白理解成：

```text
路线相似度 =
预测对的部分 / (预测对的部分 + 漏掉的真实部分 + 多预测的错误部分)
```

也就是：

```text
Jaccard = TP / (TP + FP + FN)
```

其中：

```text
TP：预测对了的真实路线节点
FP：工具多预测出来、真实路线里没有的节点
FN：真实路线里有、工具漏掉的节点
```

我们还加了深度权重：

```text
第 1 步产物权重最大；
越往后的产物权重越小。
```

因为：

```text
第一步预测错，后面路线通常就偏了；
所以前面几步更重要。
```

权重大概是：

```text
第 1 步：1/2 = 0.5
第 2 步：1/4 = 0.25
第 3 步：1/8 = 0.125
第 4 步：1/16 = 0.0625
```

起始污染物本身不计分。

然后：

```text
先给 92 个污染物每个算一个路线相似度；
再把 92 个分数取平均。
```

这就是表里的平均路线结构相似度。

## 12. 更严格评分后的结果

这次主表使用的是：

```text
92 个可评分污染物全部入分母。
没有预测结果的 case 按 0 分保留。
```

这比只看“有预测的 case”更公平。

主结果如下：

| 工具 | K=1 路线结构相似度 | K=3 路线结构相似度 | K=5 路线结构相似度 | 直白解释 |
|---|---:|---:|---:|---|
| BioTransformer | 0.197 | 0.154 | 0.152 | 整体结构最干净 |
| enviPath BBD Rules | 0.116 | 0.136 | 0.140 | 规则法中等偏弱 |
| ECLIPSE PREDEC | 0.178 | 0.106 | 0.070 | 覆盖高，但错误分支多 |
| ECLIPSE NoEC | 0.155 | 0.100 | 0.065 | 不带 EC 后整体弱一些 |

这里的 0.197 不能理解成：

```text
19.7% 的污染物完全预测对。
```

正确理解是：

```text
92 个污染物的路线图平均加权重合程度约为 19.7%。
```

具体到 BioTransformer K=1：

```text
92 个可评分污染物；
84 个有预测；
8 个没有预测，按 0 分算；
47 个至少命中了一部分真实路线；
13 个路线结构相似度超过 0.5；
5 个超过 0.8；
只有 1 个达到完全匹配。
```

完全匹配的那个是：

```text
Cyclohexane
```

## 13. 两类结果为什么看起来不一样

前面“大图覆盖率”显示：

```text
ECLIPSE PREDEC 最强。
```

后面“严格结构相似度”显示：

```text
BioTransformer 综合结构分最高。
```

原因是评价问题不同。

大图覆盖率问的是：

```text
你有没有碰到真实答案？
```

严格结构相似度问的是：

```text
你既要碰到真实答案，又不能乱猜太多错误分支。
```

所以：

```text
ECLIPSE PREDEC 的优点：覆盖能力强，容易摸到真实下游节点。
ECLIPSE PREDEC 的缺点：分支太多，错误节点也多。

BioTransformer 的优点：路线更保守，错误分支少。
BioTransformer 的缺点：覆盖能力没有 ECLIPSE PREDEC 那么强，有些 case 没预测。
```

这两个结论可以同时成立。

## 14. EC 条件有没有用

有用。

ECLIPSE PREDEC 比 ECLIPSE NoEC 明显更好。

一步预测：

```text
PREDEC Hit@10 = 74/92 = 80.4%
NoEC   Hit@10 = 52/92 = 56.5%
```

多步大图覆盖：

```text
PREDEC 任意下游节点命中 = 89/92 = 96.7%
NoEC   任意下游节点命中 = 80/92 = 87.0%
```

所以可以比较稳地说：

```text
给模型提供 EC 条件，对污染物降解产物预测是有帮助的。
```

## 15. 这次结果不能怎么说

这些说法不要用：

```text
已经预测出了完整矿化路线。
已经预测到 CO2/H2O。
已经证明真实环境里一定这样降解。
ECLIPSE 完全不行。
BioTransformer 能完整预测大多数污染物路线。
```

正确说法应该是：

```text
这次是在 BBD 已知路径范围内，做 depth≤6 的多步结构评价。
ECLIPSE PREDEC 覆盖真实下游产物能力最强；
BioTransformer 在惩罚错误分支后的综合结构相似度最高；
EC 条件对 ECLIPSE 有明显帮助；
但完整路线拓扑和终点矿化仍需要后续继续验证。
```

## 16. 当前最大限制

第一，路线没有一直走到完全矿化。

这次最多评价到：

```text
depth≤6
```

也就是最多往下看 6 步。

有 15 条真实 BBD 路线本身超过 6 步，所以这部分只评价了前 6 步以内的结构恢复。

第二，BBD-local 终点不一定是最终无害产物。

很多 BBD 路线走到：

```text
邻苯二酚、丙酮酸、乙酰辅酶A、乙醛酸、苯甲酸、琥珀酸、草酰乙酸等中心代谢或常见中间节点
```

就停了。

这通常说明：

```text
污染物已经进入更常见的代谢网络；
但不等于数据库继续记录到 CO2/H2O。
```

第三，ECLIPSE 产生的图比较大。

它容易覆盖真实节点，但也带来很多假阳性分支，所以要同时看：

```text
覆盖能力；
错误分支；
综合结构相似度。
```

## 17. 依据来自哪里

这次评价依据主要有三类：

```text
1. BBD 已知降解路线：
   用作真实答案来源。

2. enviFormer / multi-generation pathway evaluation 的思想：
   提醒我们多步路线不能只看单步 Top1，也不能只看有没有碰到答案；
   应该看整张预测路线图和真实路线图的结构重合。

3. 本地严格审计：
   HPC 只跑预测，不读答案；
   本地用 restricted answer 评分；
   所有结果有 manifest 和审计文件。
```

我们没有直接照搬 enviFormer 原版概率评分，因为：

```text
不同工具的分数不是同一种概率，不能公平相乘或比较。
```

所以我们采用：

```text
固定每一步候选数量，再比较路线结构。
```

这更适合 BioTransformer、enviPath、ECLIPSE 三类工具横向比较。

## 19. 给师姐讨论时可以用的总结

可以这样讲：

```text
我们这次把原来 BBD83 的一步产物预测，扩展成了 BBD 已知降解路线的多步预测评估。

结果分两层看：

第一层，如果只看模型有没有覆盖到真实下游产物，ECLIPSE PREDEC 最强，说明带 EC 条件的深度学习模型很有潜力。

第二层，如果用更严格的结构相似度评分，同时惩罚乱分支，BioTransformer 的综合分最高，说明它虽然保守，但路线更干净。

所以后续不是简单说哪个工具绝对最好，而是要区分使用场景：
如果我们想尽量不漏掉可能中间体，可以优先看 ECLIPSE PREDEC；
如果我们想要更保守、更少假阳性的路线，可以参考 BioTransformer；
enviPath 则适合作为可解释规则证据。

当前结果仍限于 BBD 已知路径和 depth≤6，不是完整矿化路线。
后续如果要继续做，可以考虑把 BBD 断点接到中心代谢图，或者做非 BBD 外部路线验证。
```

```text
3. 不把任何工具说成已经能完整预测矿化路线。

   - 把 BBD 路线断点往中心代谢图承接；
   - 做非 BBD 外部路线小测试集，验证是否能泛化。
```
