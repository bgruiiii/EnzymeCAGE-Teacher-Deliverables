# 代码归属、依赖与公开边界

本目录为作者已有Likert评分实现及协作阅读/运行适配的导出。此次整理不新增或擅自改成MIT等开放许可，也不改变原项目、既有合作代码和第三方依赖的权利归属。引用和后续分发应保留原出处与适用许可。

Python运行依赖`requests`、`jsonschema`遵循各自发行版许可；本目录不vendoring它们的安装包。标准库与Python解释器遵循其许可。代码来源与字节身份见`provenance/`。

没有重分发完整Gold、数据库正文、模型权重、原始请求/SSE、真实API key、账户/session信息、真实盲映射或许可未知全文。公开计数是必要的运行摘要，合成示例不是实际科学记录。实际重放历史数据需拥有相应私有输入资产和许可。
