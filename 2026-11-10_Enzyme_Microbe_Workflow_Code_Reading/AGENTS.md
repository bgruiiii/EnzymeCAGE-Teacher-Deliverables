# Reading Context

本仓库用于理解现有酶排序／微生物工作，不是部署任务。先读README及其流程、代码、模型、资产、状态导航。

- 区分逻辑流程、实际调用、历史实跑和未接通接口。不要补写不存在的production入口。
- 五模型身份、seed、旧formal和S10数据不同，不能合并描述。3B／新版EnzGFM仅为建议候选，未最终选型。
- CURRENT95评测脚本含Gold/受控池逻辑；这些不是普通推理默认。仓库没有真实Gold数据。
- t6不是CURRENT95五模型的统一部署壳；其池化和wrapper版本独立介绍。
- trait adapter注释不筛选不排序，BacDive登记不等于可下单，预测资产存在不等于已启用。
- 默认只读源码。不要运行业务main、导入业务模块、下载模型、联网查库、读密钥或连接节点。完整性检查只运行`python3 tools/check_reading_package.py`。
- 不根据文件名、路径或代码注释猜测实际部署状态；若和核实说明冲突，先查具体源码及状态说明。
- 这不是统一宽松开源许可的仓库，先读THIRD_PARTY_NOTICES。不要自行上传数据库／权重或push公开仓库。
