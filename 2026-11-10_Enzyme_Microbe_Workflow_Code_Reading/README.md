# 酶排序与微生物来源／性状工作流

**这是我方酶／微生物线的代码阅读快照，供协作者及其AI理解流程、实现和资产关系。**整理日期为2026-11-10；不含数据库、权重或特征本体，不是一个安装后即可整链运行的产品。

## 我们负责什么

起点是外部已经给定的降解路径。师兄负责的“污染物→降解路径预测”实现不在本仓库范围内。我们关注：每步反应能匹配哪些酶、如何构建和排序候选池，以及这些酶来自哪些微生物、有哪些有来源依据的性状或登记信息。

```text
给定降解路径
  ↓ 拆成单步，保留反应方向、步骤身份和分支关系
相似反应检索与Top10反应组
  ↓ 展开参考反应关联酶，按序列去重，保留多UID与来源
候选酶池
  ↓ 查找／复用反应和蛋白资产，缺件由离线工具补齐
EnzymeCAGE排序器 → 单步全排名／Top-k
  ↓ UID映射宿主，区分物种、菌株和未解析身份
微生物来源 → MetaTraits性状注释／BacDive登记相关信息
  ↓ 分清观测、缺失、预测未启用及来源分辨率
逐步结果与路径层汇总
```

这是**逻辑阅读顺序**，不是声称所有箭头已有一个连续执行入口。现有证据来自两条相关但尚未统一的实现线：

- **CURRENT95排序评测链**：冻结候选池→资产门→五模型forward→五seed集成→步骤／路径统计，2026年11月已有执行结果。本轮不重跑。
- **t6宿主／性状集成链**：含路径桥接、旧wrapper调用、宿主映射、选菌、性状和汇总组件。既有验收接受图内至选菌fail-closed＋图外同进程性状／路径汇总组件；不是连续图内端到端通过，也不是已接上CURRENT95五模型接口。

## 五模型与当前建议

保留第一版ESM-2 3B、第一版ESM-C 600M、更新数据ESM-C 600M、旧数据EnzGFM E0、更新数据EnzGFM S10五组实现和权重身份。每组为seed40–44的五个checkpoint，不是五个单seed组成五模型。

目前我方建议重点比较**第一版3B与新版EnzGFM**，再据效果等条件选用。这只是建议，不是最终生产选型，也不代表协作者必须选择二者之一。五模型差别不只参数量，数据、口袋定义与资产路线也需区分。
